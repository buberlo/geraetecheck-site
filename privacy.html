Gerätecheck (Device Check). Entwickler: Konrad Kern. Bundle-ID: de.konradkern.geraetecheck.

Diese Fassung ist die Quelle für https://buberlo.github.io/geraetecheck-site/privacy.html .

Deutsch

Gerätecheck ist eine Prüfung auf dem iPhone. Es gibt kein Konto und keinen Server des Entwicklers.

Was die App nicht tut

Es werden keine Daten an Konrad Kern oder an einen Dienst des Entwicklers gesendet. Es gibt kein Tracking, keine Werbung und keine Analyse. Der Name des Geräts wird nicht gelesen.

Was auf dem Gerät bleibt

Die Prüfung speichert das Protokoll lokal, damit sie fortgesetzt und das PDF erzeugt werden kann. Kamera und Mikrofon dienen nur dem jeweiligen Schritt. Die Mikrofonaufnahme wird danach gelöscht. Es wird kein Foto gespeichert. Bluetooth wird nur auf den Status gelesen, nicht gesucht und nicht verbunden. Bewegungsdaten und Face ID bzw. Touch ID bleiben auf dem Gerät. Face ID bestätigt nur, dass die biometrische Entsperrung reagiert. Biometrische Merkmale werden nicht ausgelesen und nicht gespeichert.

Die Speicherkapazität wird angezeigt. Das ist der einzige Zugriff, den die Privacy-Manifest-Datei meldet (Grund 85F4.1).

PDF

Das PDF entsteht auf dem Gerät. Es verlässt das iPhone nur, wenn Sie es über das Teilen-Menü selbst weitergeben.

English

Device Check runs on the iPhone. There is no account and no developer server.

What the app does not do

No data is sent to Konrad Kern or to a service he operates. There is no tracking, no advertising, and no analytics. The device name is not read.

What stays on the device

The check stores the protocol locally so it can be resumed and so the PDF can be created. The camera and the microphone are used only for the current step. The microphone recording is deleted afterwards. No photo is stored. Bluetooth is read for status only. It is not scanned and nothing is paired. Motion data and Face ID or Touch ID stay on the device. Face ID only confirms that biometric unlock responds. Biometric templates are neither read nor stored.

Storage capacity is shown on screen. That is the only required-reason API declared in the privacy manifest (reason 85F4.1).

PDF

The PDF is created on the device. It leaves the iPhone only if you share it yourself.

Purchase

The complete app is a one-time paid download from the App Store. Every feature is included, without in-app purchases or subscriptions. Apple processes payment; the developer does not receive payment details.
